# Password Generator & Strength Checker 🔐

A simple beginner Python project.

## Features
- Generate a strong random password of any length
- Check the strength of a password (score out of 5)
- Get tips to improve a weak password

## Concepts used
Functions, loops, conditions, strings, the `secrets` and `string` modules

## How to run
No installation needed, only Python 3.
```bash
python password_tool.py
```

## Sample output
```
=== Password Tool ===
1. Generate a password
2. Check password strength
3. Exit
Choose 1, 2 or 3: 2
Enter a password to check: hello123

 - Tip: 12 or more characters is even better
```
